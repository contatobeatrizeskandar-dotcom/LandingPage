# Eskandar Advogados — Landing Page

Landing page estática do escritório Eskandar Advogados, com foco em Direito do Consumidor.

## Estrutura

- `index.html` — página completa, com HTML, CSS e JavaScript inline (sem dependências de build).

## Publicação

O arquivo `index.html` está na raiz, então basta habilitar o GitHub Pages em
**Settings → Pages**, apontando para a branch padrão e a pasta `/ (root)`.
